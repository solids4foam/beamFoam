# Assessment of coupled finite-volume framework for modelling moored floating solar platforms

OpenFOAM case for  for Queen's University Belfast NEXSYS Semi-Sub FPV Collaboration.

## Case:

This case has a	moored semi-submersible floating photovoltaic platform with the mooring lines pretensioned to ~19.5N. See constant/waveProperties for the wave height and wave period used.

## Note:

Beam setup is outlined in cables_qub.

Beams have Young's modulus 4 MPa derived from treating spring & nylon mooring line as a springs in series system.
Beams have density 1140 kg/m^3 which is the density of nylon.


## Note on Waves:

Wave height – vertical distance from highest point of crest to lowest point of wave trough

Wave amplitude – vertical distance between highest or lowest point of a wave and a horizontal reference level, such as the unperturbed sea surface
